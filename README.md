# بک‌اند پروژه آشپزخانه
# کارگروه برنامه‌نویسی

## اجرای پروژه

```bash
python -m venv .venv
.venv\Scripts\activate
pip install django
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8090
```

کاربر نمونه برای ورود: کد ملی `0012345678` و رمز عبور `ashpazkhane`.

## پنل مدیریت

حساب مدیر با دستور زیر ساخته یا به‌روزرسانی می‌شود:

```bash
python manage.py create_admin
```

مقادیر پیش‌فرض: کد ملی `0000000000` و رمز عبور `admin12345`. **این رمز فقط برای محیط توسعه است؛ در محیط واقعی با `--password` یک رمز قوی بگذارید.** برای تغییر:

```bash
python manage.py create_admin --code 1234567890 --password MyPassword --first-name مدیر --last-name آشپزخانه
```

## مهلت سفارش و ظرفیت

- مهلت خرید هر وعده **ساعت ۹ صبح همان روز** است. مثلاً اگر جمعه باشد، غذای شنبه را می‌توان تا ساعت ۹ صبح شنبه خرید و بعد از آن آن روز بسته می‌شود.
- «افزودن کل ماه» روزهای بسته و پر را نادیده می‌گیرد.
- آیتم‌هایی که مهلتشان در سبد خرید تمام شده، هنگام دیدن سبد یا پرداخت خودکار حذف می‌شوند.
- اگر برای یک روز ظرفیت تعیین شود (مثلاً ۵۰ غذا)، بعد از رسیدن به این تعداد دکمهٔ خرید غیرفعال و برچسب «ظرفیت تکمیل» نمایش داده می‌شود. ظرفیت `0` یعنی بدون محدودیت.
- ساعت مهلت با متغیر `ORDER_CUTOFF_HOUR` در فایل `.env` قابل تغییر است.

## نصب روی گوشی (PWA)

سایت یک مانیفست و سرویس‌ورکر دارد. در مرورگر گوشی، از منوی مرورگر «افزودن به صفحهٔ اصلی» را بزنید تا مثل یک برنامه باز شود. برای فعال‌شدن کامل PWA، سایت باید روی HTTPS اجرا شود (یا localhost).

```bash
copy .env.example .env
```

## خرید و پرداخت

- هر کاربر برای خرید باید وارد حساب خود شود؛ افزودن به سبد و پرداخت در سمت سرور بررسی می‌شود.
- کاربر می‌تواند روزهای موردنظر یا کل یک ماه را به سبد خرید اضافه کند و همه را با هم پرداخت کند.
- هر کاربر یک سفارش «در انتظار پرداخت» (سبد خرید) و چند سفارش «پرداخت‌شده» (تاریخچه) دارد.
- مبلغ‌ها در پایگاه داده به تومان ذخیره می‌شوند و هنگام ارسال به زرین‌پال در ۱۰ ضرب می‌شوند (ریال).

### تنظیم درگاه زرین‌پال

به‌طور پیش‌فرض درگاه در حالت آزمایشی (Sandbox) اجرا می‌شود. برای تغییر، متغیرهای `ZARINPAL_*` را در فایل `.env` تنظیم کنید .

```bash
python manage.py test Menu
```
